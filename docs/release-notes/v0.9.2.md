Automatic updates, Start with Windows that survives reinstalls, and a taskbar icon that follows your accent.

## Download

| | File |
|---|---|
| Windows 10/11 (64-bit) | `Yappaflow_0.9.2_x64-setup.exe` |
| macOS 13+ (Apple Silicon and Intel) | `Yappaflow_0.9.2_universal.dmg` |

Check your download against `SHA256SUMS`. Installing over 0.9.0 or 0.9.1 keeps your settings, history and keys. **This is the last version you need to install by hand:** from now on Yappaflow updates itself.

## New

- **Updates.** Yappaflow checks for a new version shortly after it starts and every few hours. It downloads in the background and a popup offers **Restart now** (or **Later**). Nothing restarts without your click. Every update is signature-checked before it installs. Settings › About has **Check for updates**, **Install updates automatically** and a **Stable / Beta** channel.

## Fixed

- **Start with Windows** is on by default and stays on. Reinstalling used to switch it off silently. If you had turned it off in 0.9.0 or 0.9.1, this update turns it back on once; turn it off again in Settings › General and it stays off.
- **The taskbar and Alt+Tab icon** now follow your accent colour on Windows, not just the title bar and tray.

## Installing an unsigned beta

These builds are **not code-signed yet**, so your OS will warn you. Only continue if you downloaded the file from this GitHub release.

- **Windows:** SmartScreen says "Windows protected your PC". Click **More info → Run anyway**. The installer is per-user and needs no admin rights. If you pick a folder, Yappaflow installs into a `Yappaflow` subfolder inside it.
- **macOS:** open the `.dmg` and drag Yappaflow to Applications. On first launch, open **System Settings → Privacy & Security**, click **Open Anyway**, then confirm.

## Known issues

- Beta: not yet acceptance-tested on clean machines; the macOS build has had the least testing.
- Local models (whisper.cpp / llama.cpp) aren't in the installers yet.
- macOS may ask for Input Monitoring and Accessibility again after an update, because the beta isn't signed with a stable identity.

Please [open an issue](https://github.com/PexefaBuilds/yappaflow/issues/new/choose) if something breaks.
