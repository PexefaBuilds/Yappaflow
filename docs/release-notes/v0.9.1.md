A small fix release for the v0.9.0 beta's first-run experience.

## Download

| | File |
|---|---|
| Windows 10/11 (64-bit) | `Yappaflow_0.9.1_x64-setup.exe` |
| macOS 13+ (Apple Silicon and Intel) | `Yappaflow_0.9.1_universal.dmg` |

Check your download against `SHA256SUMS`. Installing over 0.9.0 keeps your settings, history and keys.

## Fixed

- **Onboarding fits the screen.** The window opens tall enough for every step (capped to your screen), and on small screens it scrolls instead of letting the provider list slide under the **Next** button. Providers are shown in two columns.
- **The microphone test can't get stuck on "Block".** Clicking Block on the microphone prompt was remembered with no way to undo it. The test no longer shows that prompt; Windows' and macOS' own microphone permission still apply.

## Installing an unsigned beta

These builds are **not code-signed yet**, so your OS will warn you. Only continue if you downloaded the file from this GitHub release.

- **Windows:** SmartScreen says "Windows protected your PC". Click **More info → Run anyway**. The installer is per-user and needs no admin rights. If you pick a folder, Yappaflow installs into a `Yappaflow` subfolder inside it.
- **macOS:** open the `.dmg` and drag Yappaflow to Applications. On first launch, open **System Settings → Privacy & Security**, click **Open Anyway**, then confirm.
