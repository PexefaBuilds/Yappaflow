See how fast each local model runs on your PC, and a sturdier local cleanup on macOS.

## Download

| | File |
|---|---|
| Windows 10/11 (64-bit) | `Yappaflow_0.9.3_x64-setup.exe` |
| macOS 13+ (Apple Silicon and Intel) | `Yappaflow_0.9.3_universal.dmg` |

Check your download against `SHA256SUMS`. If you have 0.9.2, you don't need to download anything: Yappaflow offers this update by itself. Installing over an older version keeps your settings, history and keys.

## New

- **Speed on Models › On this PC.** Each local model shows roughly how long it takes on your PC: per 10 seconds of speech for speech models, per cleanup for cleanup models. The first numbers are estimates based on your graphics card and CPU. After you've used a model a few times, they're replaced by your own average from the last 30 days.

## Fixed

- **macOS:** if Yappaflow crashed, the local cleanup server could keep running in the background. It now always stops with the app.

## Installing an unsigned beta

These builds are **not code-signed yet**, so your OS will warn you. Only continue if you downloaded the file from this GitHub release.

- **Windows:** SmartScreen says "Windows protected your PC". Click **More info → Run anyway**. The installer is per-user and needs no admin rights. If you pick a folder, Yappaflow installs into a `Yappaflow` subfolder inside it.
- **macOS:** open the `.dmg` and drag Yappaflow to Applications. On first launch, open **System Settings → Privacy & Security**, click **Open Anyway**, then confirm.

## Known issues

- Beta: not yet acceptance-tested on clean machines; the macOS build has had the least testing.
- Local models (whisper.cpp / llama.cpp) aren't in the installers yet.
- The speed estimates are rough until you've used a model a few times.
- macOS may ask for Input Monitoring and Accessibility again after an update, because the beta isn't signed with a stable identity.

Please [open an issue](https://github.com/PexefaBuilds/yappaflow/issues/new/choose) if something breaks.
