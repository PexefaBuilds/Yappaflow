Cleanup that understands what you're writing, and smarter handling of "actually".

## Download

| | File |
|---|---|
| Windows 10/11 (64-bit) | `Yappaflow_0.9.4_x64-setup.exe` |
| macOS 13+ (Apple Silicon and Intel) | `Yappaflow_0.9.4_universal.dmg` |

Check your download against `SHA256SUMS`. If you have 0.9.2 or newer, you don't need to download anything: Yappaflow offers this update by itself. Installing over an older version keeps your settings, history and keys.

## New

- **Use text near the cursor** (Settings › General, off by default). Cleanup reads up to 500 characters just before the cursor, so it can carry on a sentence you started without a stray capital letter, spell names the way they're already written, and stay in your language. That text goes to your cleanup provider along with the dictation. With local models it never leaves your PC. It's never read in password fields, code editors or terminals, and never saved. Some apps don't let other programs read their text; there it works as before.
- **"Actually" picks the option you meant.** Say "send it Monday or Tuesday, actually Tuesday" and you get "send it Tuesday". "Actually" used for emphasis ("it actually works") stays.

## Installing an unsigned beta

These builds are **not code-signed yet**, so your OS will warn you. Only continue if you downloaded the file from this GitHub release.

- **Windows:** SmartScreen says "Windows protected your PC". Click **More info → Run anyway**. The installer is per-user and needs no admin rights. If you pick a folder, Yappaflow installs into a `Yappaflow` subfolder inside it.
- **macOS:** open the `.dmg` and drag Yappaflow to Applications. On first launch, open **System Settings → Privacy & Security**, click **Open Anyway**, then confirm.

## Known issues

- Beta: not yet acceptance-tested on clean machines; the macOS build has had the least testing.
- Local models (whisper.cpp / llama.cpp) aren't in the installers yet.
- Use text near the cursor is new and hasn't been tried in many apps yet. Please report apps where it gets things wrong.
- macOS may ask for Input Monitoring and Accessibility again after an update, because the beta isn't signed with a stable identity.

Please [open an issue](https://github.com/PexefaBuilds/yappaflow/issues/new/choose) if something breaks.
