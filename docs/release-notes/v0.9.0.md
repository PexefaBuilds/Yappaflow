First public beta of Yappaflow: hold a hotkey, speak, let go, and polished text appears at the cursor in any app. Free, open source (MIT), bring your own API key.

## Download

| | File |
|---|---|
| Windows 10/11 (64-bit) | `Yappaflow_0.9.0_x64-setup.exe` |
| macOS 13+ (Apple Silicon and Intel) | `Yappaflow_0.9.0_universal.dmg` |

Check your download against `SHA256SUMS`.

## Installing an unsigned beta

These builds are **not code-signed yet**, so your OS will warn you. Only continue if you downloaded the file from this GitHub release.

- **Windows:** SmartScreen says "Windows protected your PC". Click **More info → Run anyway**. The installer is per-user and needs no admin rights.
- **macOS:** open the `.dmg` and drag Yappaflow to Applications. The first launch is blocked ("Apple could not verify…"). Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**, then confirm. Onboarding then asks for Microphone, Input Monitoring and Accessibility.

## What's in it

- Hold-to-talk dictation (Windows: hold **Ctrl + Win**; macOS: hold **fn**), hands-free mode (double-tap), Esc to cancel.
- Cleanup that removes filler words and fixes punctuation, per-app writing styles, a personal dictionary, snippets, and learning from your corrections.
- Command mode: select text, hold **Ctrl + Win + Alt** (macOS: **fn + ⌃**) and say what to change.
- Providers: OpenAI, Groq, Mistral, Deepgram, ElevenLabs, AssemblyAI, Gemini, Anthropic, OpenRouter or any OpenAI-compatible URL. Keys are kept in the OS keychain.
- History with Copy and Retry. Audio is saved before anything is uploaded, so a failed dictation is never lost.
- An estimate of your API cost on the History page.

## Known issues

- **Beta:** the on-screen acceptance tests have not been completed on clean machines yet, and the macOS build has had the least testing. Please [open an issue](../../issues/new/choose) if something breaks.
- Local models (whisper.cpp / llama.cpp) are not included in these installers yet. Build from source to try them.
- No auto-update yet. Download new versions from Releases.
- macOS may ask for Input Monitoring and Accessibility again after you update, because the beta isn't signed with a stable identity.
