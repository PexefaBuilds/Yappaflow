# Changelog

## 0.9.2

Automatic, signed updates with an update popup and About controls (Stable/Beta); Start with Windows on by default and restored after reinstalls; the taskbar icon follows the accent. See [docs/release-notes/v0.9.2.md](docs/release-notes/v0.9.2.md).

## 0.9.1

Onboarding fits the screen and keeps Next below the content; the microphone test can no longer get stuck on "Block". See [docs/release-notes/v0.9.1.md](docs/release-notes/v0.9.1.md).

## 0.9.0 (public beta)

First public release. Windows installer (NSIS) and a universal macOS `.dmg`, both unsigned. See [docs/release-notes/v0.9.0.md](docs/release-notes/v0.9.0.md) for features, install steps and known issues.
