# Third-party notices

This file is a placeholder. The release workflow (`.github/workflows/release.yml`, job `notices`)
replaces it with the full list of Rust crates (`cargo about`, see `src-tauri/about.toml`) and npm
packages (`license-checker-rseidelsohn`) inside the build, and bundles it into the installers.

Generate it locally with the same commands as the `notices` job.
